# Steal an Egg Macro

Free auto-farm macro for Steal an Egg - hatches and collects on a loop while you are AFK. Windows 10/11, small installer.

## What it does

Hold mode keeps a key pressed for as long as you set, which is what hatching in bulk actually needs - not a burst of clicks, a steady hold. Loop mode repeats a recorded sequence for the walk to the eggs and back. Both can run together, one on a short interval and one on a long one, so a session does not stall when a stack runs out.

## Features

- Hold mode: keeps a key pressed for a set duration
- Loop mode: repeats a recorded sequence
- Both modes can run together on different intervals
- Random jitter on every delay
- Global hotkey to start and stop without leaving the game
- Named profiles for different eggs and spots
- Run counter showing completed loops
- Small installer, no extra components, free and open source (MIT)

## Install

1. Download the latest release: **[Steal an Egg Macro](https://github.com/OWNER/steal-an-egg-macro/releases/latest)**
2. Run the installer. No admin rights, no extra components.
3. Start it from the Start menu.

Windows 10 and Windows 11, 64-bit. Nothing else is required.
